# Sobhy Youssef’s portfolio

A static personal portfolio for the GitHub Pages user site at https://sobhyalbert.github.io/. The site uses plain HTML, CSS, and JavaScript.

## Preview locally

From this directory, run `python3 -m http.server 8000` and open http://localhost:8000/.

## Publish later

When ready to publish, use the `SobhyAlbert/sobhyalbert.github.io` repository. Place the site files and the referenced assets at the repository root, keeping `.nojekyll` alongside `index.html`. In the repository’s **Settings → Pages**, select **Deploy from a branch**, choose the branch containing the site, select **/ (root)**, and save.
